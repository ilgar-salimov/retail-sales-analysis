#Data Overview

The data folder contains structured CSV files used in the retail sales analysis project. The dataset is primarily inspired by the classic Northwind database schema, with additional enhancements to support advanced SQL analysis and reporting.

Each file represents a specific business entity, and together they form a relational data model suitable for analytical queries, data warehousing, and integration with business intelligence tools such as Power BI.

Additionally, a custom Date dimension table is created to enhance time-based analysis. This table contains attributes such as year, month, day, week number, and day name, enabling efficient time intelligence in both SQL queries and BI visualizations.

The dataset follows a relational structure with defined primary and foreign key relationships between tables.
